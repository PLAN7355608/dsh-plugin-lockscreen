## 一、怎么用

| 操作 | 效果 |
| --- | --- |
| 打开 / 刷新 DSH | **默认直接进锁屏**（「打开应用就锁屏」默认开；还没设过口令时不锁）；会先播 5 秒"启动自检"（全英文，键鼠不响应、不能跳过），**同一个会话只演一次**，之后按 F5 不再重播 |
| `Ctrl+Shift+L` | **锁屏**（锁着的时候再按它不会解开，必须输口令） |
| 输入口令后 `Enter` | 解锁，回到原来的界面（不刷新、不丢现场） |
| **`F`** | 进 / 出"真全屏"（连任务栏一起盖住），结果会显示在画面底部一行小字里 |
| 鼠标 | 锁屏时**默认彻底禁用**：指针看不见、点击 / 右键 / 滚轮 / 拖拽都没反应，只能用键盘。想恢复在设置页「锁屏时禁用鼠标」里关掉 |

### 第一次锁屏：先设口令

第一次按 `Ctrl+Shift+L` 时，解锁区显示的是**设置面板**：

- `数字 PIN`：正好 4 位数字（例如 `0823`）
- `文字口令`：**至少 6 位**、最多 64 位，中文也行

两种都可以，选一种设好即可。设完**仍然是锁着的**，要再输一遍刚才设的口令才解开（故意的，顺便当场验证一遍没打错字）。

### 连错怎么办

连错 5 次 → **冷却 30 秒**，面板上显示"还剩 N 秒"，数到 0 自动恢复，期间输入框是禁用状态。

### 口令是怎么存的

- 只存 **PBKDF2-SHA256（21 万轮）+ 16 字节随机盐** 算出来的摘要，**不存明文**；
- 存在 DSH 的本地存储里（`lockscreen.cred`），旁边还有 `lockscreen.fails`（连错次数）、`lockscreen.cooldownUntil`（冷却到什么时候）；
- 因为不存明文，所以**没有"找回口令"这回事**；忘了只能按下一节重置。

### 忘了口令怎么重置

三步（不用懂代码，照着点）：

1. 先按 `F12` 打开开发者工具（`「打开应用就锁屏」`开着时按 F5 会重新锁上，所以这一版是"进控制台"而不是"刷新绕过"）；
2. 切到 `Console` 面板；
3. 粘贴这行并回车：

```js
localStorage.removeItem('lockscreen.cred'); localStorage.removeItem('lockscreen.fails'); localStorage.removeItem('lockscreen.cooldownUntil')
```

4. 再按 `F5` 刷新 —— 因为没有口令了，这次**不会再锁**，进去重新设一个即可。

（如果哪天 F12 也打不开，退路是：在设置页「打开应用就锁屏」关掉——但那需要先解锁，所以真正的兜底是把 `lockscreen.cred` 清掉，见上面。）

## 二、设置面板在哪里

**DSH 设置页 → 左边找「锁屏」**（插件自己在设置页里加的一个分区）。面板里能改八样东西，改完立刻生效，不用刷新：

| 区域 | 能干的事 |
| --- | --- |
| **口令** | 看当前是"没设过 / 4 位数字 PIN / 文字口令"和设置日期；**修改口令**（要先输一次现在的口令）、**清除口令**（要再确认一次） |
| **解锁与错误**（0.1.4） | 连错几次就锁（3 / 5 / 7 次，默认 5）、锁多久（30 / 45 / 60 秒，默认 30）。见下面「二之二」 |
| **留言** | 锁屏画面"留言"那一行显示的文字，一行；也能"恢复默认"。0.1.4 起还能开**滚动字幕**（慢/中/快）、选**字号**（小/中/大）、开**逐字变色**（默认关） |
| **已锁定时长** | 开关。打开后锁屏画面日期下面多一行 `已锁定 03:12`；**默认关闭** |
| **锁屏时禁用鼠标** | 开关。打开后锁屏时指针隐藏、点击/右键/滚轮/拖拽全无效；**默认打开** |
| **打开应用就锁屏** | 开关。打开后每次启动 / 刷新 DSH 都直接进锁屏；**默认打开** |
| **自动落锁** | 见下面「二之一」：空闲多久自动锁、切走锁不锁、锁前要不要倒计时；**默认关闭** |

为什么不把设置放在锁屏画面上：锁屏时屏幕上多一个按钮，就等于给路过的人一次改口令的机会。设置页只有在"已经解锁、能进 DSH"时才打得开。

**左边那一行现在是小锁图标**（0.1.3 起）：DSH 的 `settings.section` 插槽没有 `icon` 字段，第三方分区默认全是齿轮；插件学 `dshmarket` / `dsh-better-sidebar` 的做法，等设置页挂上后认出"文字是「锁屏」"的那一行，用 CSS mask 把齿轮换成小锁（颜色跟着导航文字走，hover / 选中自动变色）。哪天真加了 `icon` 字段，这段就可以删。

### 二之二、解锁与错误 / 留言显示（0.1.4 新增）

**连错的处理**（这是 0.1.4 最大的改动）：

| 设置 | 默认 | 可选 |
| --- | --- | --- |
| 连错几次就锁 | 5 次 | 3 / 5 / 7 次 |
| 锁多久 | 30 秒 | 30 / 45 / 60 秒 |

输错到上限后，锁屏**不再停在输入框上**，而是切到一个单独的出错页 —— 做成电影片尾**谢幕表**那样：字幕从画面底部往上一直滚。

- 字幕是七种语言各一块（中文 → English (US) → English (UK) → Français → Русский → Español → العربية），每块都是「黄色警告三角 + 红底白字 WARNING + 一句带**具体法条和处罚**的警告词」（中国《网络安全法》27 条 + 刑法 285②/286①、美国 18 U.S.C. §1030(a)(2)、英国 CMA 1990 s.1、法国 323-1/323-2、俄罗斯 ст.272、西班牙 197 bis、沙特《反网络犯罪法》三/五条）；
- 正文**两端对齐**、末行贴起始边（阿拉伯语自动贴右边）；块与块之间留白加宽，滚起来不糊成一片；
- 底部三行（`RESUME IN NN s` 倒计时 / ASCII 进度条 / 返回按钮）**固定不动**，只有中间的字幕在滚；
- 冷却走到 **3/4**（30 秒就是第 22.5 秒）时，底部出现 `[ 返回再试 ]`，按 Enter 或点它就能回输入页；
- 回去的瞬间**连错次数清零**，但冷却还在走剩下那一小段——这段时间输入框仍然禁用，并显示"冷却中，还剩 N 秒"；
- **冷却到点不会自动跳回**：字幕继续循环滚（当屏保用），只把底部倒计时换成「冷却已结束 · 按 Enter 返回」；什么时候回去由你按返回决定。
- 循环是**无缝**的（0.1.4 修复）：一共两份同样的字幕，滚动的位移正好等于一份的高度，所以滚到底的那一帧和第二份的开头逐像素相同，接缝看不出来，不会"跳回开头"。

**隐形按钮**（0.1.4 新增，纯给键盘 / 调试用）：

锁屏画面里按一下 `Tab`（光标本来就在口令框里），口令框下面会亮出一条**反色高亮**：`> 预览出错页  [Enter]`。

- 按 `Enter` 直接进上面那个谢幕表出错页 —— 画面文案、倒计时、进度条**跟真出错时一模一样**，用来调样式或演示；
- `Esc`（或 Enter / 空格）随时退回输入页，光标自动回到口令框；
- 它**不动真的连错计数、不写冷却**，平时完全看不见（`opacity: 0`），只有 Tab 聚焦到才亮。

**留言的显示**：

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 滚动字幕 | 关 | 打开后，留言比一行长才从右往左滚；短留言不动 |
| 滚动速度 | 中 | 慢 / 中 / 快 = 每秒 6 / 10 / 16 个字 |
| 留言字号 | 中 | 小 / 中 / 大 = 0.9 / 1.0 / 1.35 倍 |
| 逐字变色 | 关 | 每个字颜色不同、还会慢慢转色（彩虹跑马灯那味儿）。默认关，因为跟整套终端风格不太搭 |

### 二之一、自动落锁（0.1.3 新增，默认关）

只在你**已经解锁、并且设过口令**的时候才干活（没口令就自动锁 = 把你自己永久关在门外，所以不做）。

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| **自动落锁** | 关 | 总开关。打开后"在 DSH 里连续这么久没有键盘 / 鼠标 / 滚轮动作"就锁屏 |
| 空闲多久算该锁了 | 5 分钟 | 可选 1 / 3 / 5 / 10 / 15 / 30 / 60 分钟 |
| 切到别的软件也要锁吗 | 关 | DSH 窗口失去焦点（你切到浏览器、微信…）也锁 |
| 切走后多久锁 | 30 秒 | 可选 立刻 / 30 / 60 / 120 秒 |
| 快锁之前先倒计时几秒 | 开 | 最后几秒在画面底部显示 `AUTO-LOCK 05s · 动一下键鼠就取消`，动一下键鼠就重新计时 |

两条要点：
- **只能看见 DSH 窗口里的操作**。你在别的软件里敲键盘，插件是看不见的——所以"空闲"指的是"DSH 窗口里没动静"，不是"整台电脑没动静"。
- 切走锁默认关，因为频繁切窗口时开着会很烦；开着的话，回到 DSH 窗口（重新获得焦点）会立刻取消这次计时。

## 四、已知限制（重要，别当 bug）

1. **这是"软锁"，不是系统登录锁**：防的是"路过的同事看一眼屏幕"，不是防专业的人。任务管理器强杀 DSH、`Alt+Tab` 切走都绕得过去。
2. **`F5` 刷新会重新锁上**（「打开应用就锁屏」默认开着）。0.1.0 时代是"刷新即解锁"，0.1.1 起改成"刷新也锁"——因为 0.1.0 那个口子等于谁都能按一下 F5 绕过锁屏。想恢复旧行为：设置页 →「打开应用就锁屏」关掉。真忘口令的退路见上面"忘了口令怎么重置"。
3. **左上角"应用 / 编辑"菜单盖不住**：那是 Electron 原生菜单栏，由浏览器外壳绘制，网页层的 z-index 再大也压不住；右下角的小鲸鱼娘挂件同理（DSH 自己的顶层容器）。这两处已确认，属于"知道就行"。
4. **只盖住 DSH 这个窗口**：别的程序窗口、其他显示器都不受影响；"锁屏时禁用鼠标"也只在这个窗口内生效——**系统层面的鼠标（桌面、别的软件）插件管不了**（需要操作系统/驱动级权限）。
5. **口令校验需要"安全上下文"**：DSH 界面是 `127.0.0.1`（属于安全上下文）所以没问题；如果哪天用普通 `http://` 局域网地址打开，浏览器不给用加密接口，面板会提示"当前界面不是安全上下文…无法加密口令"。
6. **启动自检的"进度条"是演的，不是真下载进度**：模块总数（89）是真的、`modules loaded N/89` 按时间走；5 条"检查项"也没有真的检测，只是随进度条依次点亮。原因见 PLAN 6.13：插件必然排在最后一个包里执行，等它能跑的时候别人早加载完了；想画真进度条得改 `dsh.profile.bundles`（用户已明确不做）。0.1.1 起**第一帧由后台半边注入首页**，所以"开机就有画面"这件事是真的，不再有 DSH 加载卡片露脸。
7. **首帧配色是靠 `prefers-color-scheme` 猜的**（那一刻 DSH 自己的主题还没套上）：如果你的系统是浅色、DSH 用的是深色（或反过来），开头几帧的颜色会跟后面不一致，前端接手后立刻纠正。不是 bug。
8. **自检动画不能跳过**（有意为之）：这 5 秒里键盘鼠标都不响应，按 Esc 也不会进锁屏。另外它**每个 DSH 会话只演一次**，之后按 F5 刷新不再重播（记在 `sessionStorage` 里，关掉 DSH 重开才再演）。
9. **自动落锁只在 DSH 窗口里算"有没有动静"**：你在别的软件（浏览器、微信、IDE…）里敲键盘，插件看不见，所以那边敲半天也算"DSH 里空闲"。想让"整台电脑闲置"也锁，得靠操作系统自己的锁屏，插件做不到。另外**没设过口令时自动落锁不生效**（防止把没口令的人永久关在门外）。

## 五、万一画面关不掉

- 真锁屏时 `Esc` **故意无效**（能 Esc 关掉就不叫锁了），路是：输口令，或者 F12 清掉本地存储再刷新（见"忘了口令怎么重置"）。
- 若按了 `F` 进了真全屏，浏览器的固定行为是**第一次 `Esc` 先退出全屏**；预览模式下第二次 `Esc` 才关掉画面。

## 六、怎么装 / 怎么卸

装：DSH → 插件页 → 添加插件 → 输入本机路径 `E:\bigbluefishWorkbench\lockscreen-plugin` → 安装。
本项目是用**目录链接（Junction）**装进去的，所以改完文件：
- 改 `client.js`（画面 + 锁屏逻辑）→ 按 `F5` 刷新就生效；
- 改 `index.js`（后台）→ 要**重启 DSH** 才生效。

卸：插件页里卸载即可，不在系统里留任何东西（本地存储里的三条 `lockscreen.*` 可以按上面的命令清掉）。
